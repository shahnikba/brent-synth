**Location: synthetic median inside the real 2.5–97.5% bootstrap band.**
The real return process is the null hypothesis. A single 252-day sample of
it produces a statistic that lands somewhere in a distribution; the band is
the central 95% of that distribution, so a synthetic median outside it is
a two-sided rejection at the 5% level. The band is generated by a
stationary block bootstrap rather than an iid one because an iid resample
destroys the clustering the model is being tested on and would wrongly
reject any clustering model.

**Dispersion: synthetic 2.5–97.5% width within 0.5–2.0x the real band.** A
model can sit on the median and still be wrong about how variable a year
of Brent can be; the location test cannot see that. The bounds are
deliberately loose because both widths are themselves estimated from
finite samples (5000 paths, 2000 replicates), so a flag means the model
generates years at least twice as variable, or half as variable, as the
market — a gross mismatch, not a marginal one. A stricter warn tier at
0.67–1.5x would additionally flag ES 95%, the 1st percentile return and
the 99th percentile return (1.86x, 1.83x, 1.65x); they are reported in the
table so a reader can apply that tier themselves.

**Why per path, on both sides.** Every statistic is computed on exactly
252 observations for each synthetic path and each bootstrap replicate,
then the distributions are compared. Pooling all 1.26M synthetic days into
one sample would mix paths whose realised volatility differs by an order
of magnitude and manufacture kurtosis and autocorrelation that no single
path has. The two marginal-density plots in §3 (histogram, QQ) *are*
pooled, deliberately: an unconditional marginal over many regimes is the
right object to compare against 4753 real days spanning many regimes, and
those plots are read as marginals, not as path statistics.
